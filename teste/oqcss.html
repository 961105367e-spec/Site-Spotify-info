Pesquisa sobre css:

CSS (Cascading Style Sheets)

linguagem de estilo que descreve a apresentação visual de documentos HTML ou XML, controlando as cores, fontes, espaçamento e disposição dos elementos numa página web.

  • Mudar cores de fundo, textos, botões, menus etc.
  • Escolher tipos de fonte, tamanhos e espaçamentos.
  • Colocar imagens de fundo.
  • Posicionamento de elementos

O CSS é utilizado para:

Deixar páginas HTML bonitas, organizadas e funcionais. Sem ele, todo site seria só texto preto e branco, sem nenhum estilo.
